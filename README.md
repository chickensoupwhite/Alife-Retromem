# RetroMem (溯忆) v5.2.0

> *Like old times passing by*

### 项目愿景
真正的陪伴，不该是一场随窗口关闭而消散的短暂会面，更不该是未经提炼、充斥杂音的机械式流水堆砌。
溯忆（RetroMem）跳出“无限拼接上下文”的粗放模式，确立以**“经历＋长期认知”**为核心的双轨沉淀体系，赋予智能体真正属于自己的时间线、沉淀感与主权记忆。

每个角色的记忆与认知数据物理隔离，独立保存在专属的 SQLite 数据库中。

---

### 核心功能特性

#### 1. 记忆提炼与认知归纳
- **经历提取**：从原始交互流水中提炼客观、精简的事实性片段（经历）
- **认知沉淀**：基于多维经历提炼持久的长期认知，严格区分客观事实与主观印象
- **独立存储**：角色业务数据各自独立建库，杜绝数据交叉污染

#### 2. 来源管理与后台追赶
- **信源只读保护**：默认读取底层记忆（L1 与 L100），严格保持信源只读，自动追踪增量变更
- **后台异步追赶**：内置追赶机制无感消化历史积压，支持暂停、恢复与断点进度展示
- **独立模型调度**：支持为主流程与后台整理分别指定模型，降低交互延迟与资源竞争

#### 3. 群聊参与闸门
- **活跃窗口过滤**：依据角色实际发言状态动态开启接收窗口，仅保留有效参与及窗口期内的相关旁听
- **噪声拦截**：物理过滤群聊无关流水，防止记忆张冠李戴，保障角色的自我边界

#### 4. 混合检索与动态补充
- **三阶检索架构**：结合关键词精确匹配、向量语义检索与本地 Cross-Encoder 精排重排
- **多维组合筛选**：支持按人物、记忆类型、时间范围（自然语言解析）及分页检索
- **平滑记忆注入**：根据实时对话自动召回匹配记忆，严格控制单次上下文注入量与触发频率，内置防重机制

#### 5. 人物画像与共现图谱
- **立体人物档案**：维护人物认知、印象、关联经历与简介，支持多称呼管理及同人合并与解绑
- **交互式关系图谱**：以力导向图可视化展示人物、主题与事物的共现关联，支持拖拽联动、聚焦回弹与底层依据穿透

#### 6. 提案审阅与审计可溯
- **冲突与冗余仲裁**：自动检测重复、近似与冲突提案，提供接受、拒绝、合并、以新替旧、保留双方等多维度决策
- **原文证据链**：每条记忆均绑定原始文本摘录与出处位置，保留完整修订轨迹与操作审计，关键变更支持一键撤回

#### 7. 记忆生命周期与维护
- **状态流转**：支持正文与时间编辑，提供活跃、已完成、已过期及回收站恢复机制
- **运维保障**：支持数据库热备份、JSON 导入导出、向量索引重建以及模型与检索链路诊断

#### 8. 可视化控制台与开箱即用
- **专用角色工具**：角色可自主发起检索、审阅提案、核对人物与查验未完成事项
- **多元界面风格**：提供管理控制台与插件配置页，支持迈阿密、玻璃、黑白紫、黑夜等多套主题与磁带机械音效
- **完整环境集成**：内置独立 Python 运行环境及本地向量、精排模型，零外部依赖，即插即用
